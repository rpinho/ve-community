## ve-stagecheck: specimen-level public atlas sheet triage

An offline Python tool that checks CSV, TSV and SDRF public atlas sample sheets
against the Challenge's published external-data stage windows, with one decision
per biological sample. It extends existing stage-rule guidance with repeated
record grouping, explicit age intervals and uncertainty, and manual-review flags
for litter ages and morphological staging; all tests use invented metadata.

## ve-community-selection: Choosing what to submit without fooling yourself

A [synthetic-only executable tutorial](tutorials/selection/README.md) explains
selection bias, validation quirks, sealed finalist acceptance, paired seeds and
expected improvement for a final best-of-k attempt. It includes a dependency-free
Python script and pytest checks, and credits existing candidate-selection and
winner's-curse contributions found in the live register. This local draft makes
no claim to invent those topics and uses no challenge data or real run results.
